# Telecom Customer Churn Prediction

## Project Overview
This project predicts whether a telecom customer is likely to churn using machine learning.

## Dataset
IBM Telco Customer Churn dataset. The dataset contains 7,043 customer records.

## Machine Learning Models
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Support Vector Machine (SVM)

## Evaluation Metrics
Accuracy, AUC, Precision, Recall, F1 Score, and Matthews Correlation Coefficient (MCC).
